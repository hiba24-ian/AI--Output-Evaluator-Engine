# AI Output Evaluator & QA Engine

A reproducible Python project that evaluates sample model outputs against explicit test-case requirements, with JSON/Markdown reporting and an interactive Streamlit dashboard.

## What it checks

- **Expected keyword coverage:** checks whether required phrases appear in an output (case-insensitive).
- **Minimum output length:** checks whether an output meets a configured character minimum.
- **Pass/fail reporting:** records matched and missing keywords, individual check results, failure reasons, and the overall pass rate.
- **JSON report:** saves structured results to `reports/evaluation_results.json`.
- **Readable Markdown report:** creates `reports/evaluation_results.md` with a summary table and per-case details.
- **Interactive dashboard:** displays pass/fail metrics, a chart, a results table, and expandable test-case details. It can use the built-in sample data or accept an uploaded test-case/report JSON file.

## Important scope

This is a **rule-based baseline evaluator**. It does not call an LLM and does not determine whether an answer is factually correct, contextually appropriate, safe, or semantically equivalent to an expected answer. Keyword presence is a simple, explainable signal, not a complete measure of AI quality.

## Requirements

- Python 3.10 or newer
- Standard library for the command-line evaluator and tests
- Streamlit (optional) for the interactive dashboard

## Run the evaluator

From the repository root:

```bash
python main.py
```

Optional input, output, and keyword threshold:

```bash
python main.py --input data/test_cases.json --output reports/evaluation_results.json --threshold 0.8
```

The threshold must be between `0.0` and `1.0`.

## Run the interactive dashboard

Install the dependencies and start Streamlit:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The dashboard opens in your browser. It loads `data/test_cases.json` by default. You can also upload either a JSON list of test cases or a JSON evaluation report generated by this project.

## Run tests

```bash
python -m unittest discover -s tests -v
```

The tests cover successful evaluations, missing keywords, insufficient length, case-insensitive matching, invalid test cases, threshold validation, empty test suites, and Markdown report generation.

## Test-case format

Each item in the input JSON list must include:

- `id`: descriptive case identifier
- `prompt`: the task given to the model
- `model_output`: the response being checked
- `expected_keywords`: list of required phrases (an empty list skips keyword matching)
- `min_length`: minimum number of characters required

## Reports

The command-line evaluator generates both a machine-readable JSON report and a human-readable Markdown report. Reports are generated locally and are not committed automatically.
